# SLOWHAND ∞

エリック・クラプトンスタイルのブルースギターソロを、止めるまで無限に自動演奏するWebアプリです(React + Tone.js)。12小節ブルース進行の上で、130本のリックライブラリとバリエーション・エンジンがソロを即興生成し、ピアノ/ベース/ドラムのトリオがそれを「聴いて」反応します。

- **ギター**: サンプラーベース(単音サンプル+ピッチカーブのリアルタイムオートメーション)。チョーキング4種(1/4・半・全・1音半)、タメの効いたチョークアップ、粘るビブラート、スライドイン、トリル、レットリングのアルペジオ、ピッキングハーモニクス、フィードバック、運指ノイズまで実装
- **フレージング知能**: ガイドトーン(コードチェンジで長3度を狙う)、モチーフ反復とクレッシェンド、キメフレーズ、テーマ回収、フレーズ内位置で変化するスウィング、半拍裏からの入り
- **バンド**: ギターの手数にピアノが反応し、高音ロングトーンで決めるとギターのフレーズをモチーフ引用して装飾符付きで歌い返します。盛り上がるとドラムはライドに持ち替え
- **音色**: PigNose風ナチュラルオーバードライブ〜ディストーション(非対称指数カーブ+整流管サグ)、ウーマントーン、BPM同期ワウ、キャビネットシミュレーション、ステレオ定位
- **時代セレクタ**: おまかせ / Cream期 / Dominos期

## セットアップ

```bash
npm install
npm run fetch-samples   # サンプル音源(ピアノ8+ギター12ファイル)を取得
npm run dev
```

ブラウザで http://localhost:5173 を開いて「セッション開始」。

サンプル音源(Salamander Grand Piano、guitar-electric — いずれもCC BY 3.0、詳細は[CREDITS.md](CREDITS.md))はリポジトリに含まれておらず、`fetch-samples`で各配布元から取得します。取得しなくても動作します(その場合はFM合成/シンセ合成にフォールバック)。UIのヘッダに「PIANO: Salamander Grand」「GTR: サンプラー(12音)」と表示されれば読み込み成功です。

なおUIのスタイリングにTailwind CSSのPlay CDN(バージョン固定)を使用しているため、初回表示にはネットワーク接続が必要です。音源はサンプル取得後は完全ローカルで動作します。

## 機能メモ

- **録画(MP4)**: キャンバス映像+マスター音声をMediaRecorderで保存。MP4非対応ブラウザ(Firefox等)は自動でwebmになります。Chrome/Edge/Safari推奨
- **MIDI保存**: 演奏ログをSMF形式(Type 1)で書き出し。トラック構成はテンポ/ギター(ch1)/ピアノ(ch2)/ベース(ch3)/ドラム(ch10)。ギターはチョーキング・ビブラート等をピッチベンドカーブ(RPNでベンドレンジ±12半音を設定)として記録します。停止後でも直前のセッションを保存可能
- **ワウペダル**: 歪み前段のレゾナントバンドパスをビート(BPM)に同期して揺らします。Cream期+ウーマントーンOFFとの組み合わせが1968年風
- テンポを変えて録ったMIDIは書き出し時点のフィールのBPMで量子化されるため、フィールはセッション中固定を推奨

## 謝辞

本プロジェクトのブルースの語彙——3度のメジャーとマイナーの使い分け、チョーキングの使い所、裏拍から入る呼吸——は、松尾宗人(Muneto Matsuo)の助言によるものです。そしてその基礎は、早逝した友人・永田英樹(Hideki Nagata)——「おっさん」——から受け継がれたものです。このエンジンが弾き続けるかぎり、ふたりの教えはここで鳴り続けます。

## 左手の検査

指板に描く運指は、実際に左手が辿れるものでなければ意味がありません。全数検査を用意してあります。

```bash
npm run audit:hand
```

手を4フレット幅(第8フレット以上は5フレット)とみなし、ポジションの外へ出る音が **スライド系の奏法** か **2単位以上の間合い** で覆われているかを、全リック×全調で調べます。覆われていない3フレット以上の移動が3%を超えると失敗します。

現状は 4,158音中 65件(1.56%)。
